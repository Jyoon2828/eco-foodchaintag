# 먹이사슬 술래잡기 — 개인 체험용 1.2

4학년 과학 ‘생물과 환경’에서 네 동물 역할을 맡아 먹이관계를 체험하는 웹게임입니다. 다른 선생님께 이 압축파일을 그대로 공유하셔도 됩니다.

## 1.2 배경 음악과 효과음

‘숲속 탐험 시작하기’를 누르면 기본 음량 35%로 잔잔한 숲속 BGM이 시작됩니다. 첫 화면에서는 자동으로 소리가 나지 않습니다. 위쪽 **♫ 소리 설정**에서 BGM과 효과음을 따로 켜거나 끄고, 전체 음량을 0~100%로 바꿀 수 있습니다. ‘효과음 들어보기’로 음량을 확인할 수 있습니다. 설정은 열린 페이지 안에서 유지하며, 새로고침하면 기본값으로 돌아갑니다.

- 내 캐릭터의 먹이 먹기, 메뚜기 점프, 개구리 혀 뻗기, 뱀 숨기, 매 내려오기, 잡힘에 서로 다른 소리를 넣었습니다.
- 먹이 미션 성공, 역할 종료, 퀴즈 정답·다시 도전, 전체 탐험 완료를 짧은 소리로 알려 줍니다. 미션 성공음은 한 역할에서 한 번만 나옵니다.
- 컴퓨터 생물끼리의 행동에는 효과음이 나지 않습니다. 같은 효과음의 빠른 중복을 제한합니다.
- 잠깐 멈춤, 도움말, 소리 설정에서는 BGM과 진행 중인 행동 소리가 멈춥니다. 설정 창 안의 미리 듣기는 사용할 수 있습니다. 퀴즈 중에는 BGM이 쉬고 정답·오답 효과음만 나옵니다.
- 다른 탭으로 가거나 창이 비활성화되면 재생 중인 소리를 모두 멈춥니다. 돌아와 ‘계속 탐험하기’를 누르면 BGM도 다시 시작합니다.

음악의 선율과 효과음은 이 게임용으로 만든 소리를 브라우저의 Web Audio 기능으로 합성합니다. 외부 음원, 추가 다운로드, 유료 서비스 연결이 없습니다. 소리를 지원하지 않는 브라우저에서도 게임은 계속할 수 있습니다. 기기의 음소거 상태와 미디어 음량도 확인해 주세요.

## 1.1 움직임과 먹이 배치 개선

화면 갱신 사이에 이동 계산이 없는 순간마다 걷기 표시가 꺼졌다 켜지던 문제를 고쳤습니다. 60회/초 게임 계산 사이의 위치를 이어 그려 60·90·120Hz 화면에서 고르게 이동합니다. 빠른 상하 들썩임을 줄이고, 메뚜기·개구리는 작고 느린 몸짓, 뱀은 땅을 따라 움직이기, 매는 완만하게 떠 있기로 다듬었습니다. 대각선에서 그림 방향이 반복해서 바뀌는 현상도 줄였습니다.

컴퓨터 생물은 목표와 이동 경로를 잠시 유지하며 천천히 방향을 바꿉니다. 먹이가 되는 동물의 속도는 학생 동물보다 낮추고, 컴퓨터 메뚜기의 도약 간격은 8초로 늘렸습니다. 학생 메뚜기의 점프 대기시간은 계속 4초입니다.

기본 ‘처음 숲 친구 12마리’ 설정에서 다음처럼 먹이를 보강합니다.

| 학생의 역할 | 숲에 배치하는 먹이 |
|---|---|
| 메뚜기 | 벼 24곳, 먹은 뒤 다시 자람 |
| 개구리 | 메뚜기 8마리 |
| 뱀 | 개구리 7마리 |
| 매 | 뱀 6마리 |

동물 먹이 중 세 마리는 시작 위치 근처에 배치합니다. 동물 역할이 바뀔 때 숲 친구 구성을 새로 맞추므로 중복 누적되지 않습니다. 보통 설정의 전체 숲 친구 수는 차례로 12·13·15·17마리입니다. 8·16마리 시작 설정에서는 먹이 수도 비례해서 조절됩니다. 기존 먹이 미션 목표는 유지합니다. 미니맵에는 내 동물이 먹을 수 있고 시야에 보이는 동물 먹이도 노란 점으로 표시합니다.

업데이트할 때는 새 `index.html`을 교체하고 새로고침하세요. 그림과 코드가 모두 그 파일 안에 들어 있습니다.

## 바로 실행하기

1. 압축을 풉니다.
2. **`index.html`을 엽니다.** 컴퓨터에서는 더블클릭해서 브라우저로 열 수 있습니다.
3. ‘숲속 탐험 시작하기’를 누릅니다. 이름·모둠·학급 코드를 입력하지 않습니다.

`index.html` 한 파일에 그림·화면·게임 코드가 모두 들어 있습니다. 이 파일만 복사해서 실행해도 됩니다. 파일을 받은 뒤에는 인터넷 없이 실행할 수 있습니다. 태블릿에서 HTML 파일 열기가 불편하면 아래 방법으로 배포한 웹주소를 공유하세요.

## 여러 학생에게 링크로 공유하기

학생 여러 명이 같은 주소를 열어도 **각자 다른 숲에서 혼자** 진행합니다. 학생들의 캐릭터가 서로 만나는 방식은 아닙니다. 교사에게 결과를 전송하거나 모둠끼리 동기화하지 않습니다.

### GitHub + Vercel

1. 새 GitHub 저장소를 만들고 **이 폴더 안 파일**을 올립니다. 저장소 최상위에서 `index.html`이 보여야 합니다. 개인용은 기존 학급 공동접속용과 다른 저장소에 올리는 것이 편합니다.
2. Vercel에서 새 프로젝트로 가져옵니다.
3. Framework Preset은 **Other**로 선택합니다. Build Command와 Install Command는 비워 두고, Output Directory는 기본값으로 둡니다. 이미 완성된 정적 HTML이므로 빌드할 필요가 없습니다.
4. 배포된 주소를 다른 선생님이나 학생에게 공유합니다.

**Firebase 프로젝트, 환경 변수, API 키, 로그인 계정은 모두 필요 없습니다.** Firebase SDK·데이터베이스·분석 도구를 사용하지 않습니다. 화면에서 외부 글꼴이나 그림을 내려받는 요청도 없습니다.

GitHub Pages 등 일반 정적 웹 호스팅에도 올릴 수 있습니다. `index.html`만 서비스하면 실행됩니다.

## 체험 흐름

1. 메뚜기 → 개구리 → 뱀 → 매 순서로 네 역할을 맡습니다.
2. 먹이를 찾고 천적을 피하며 먹이 미션에 도전합니다.
3. 각 역할이 끝나면 먹이관계 한 문제를 풉니다. 틀리면 설명을 보고 다시 고를 수 있습니다.
4. 학생이 ‘다음 역할로 출발하기’를 눌러 계속합니다.
5. 네 역할을 마치면 역할별 먹이 미션 기록과 먹이사슬을 봅니다.

기본 설정은 **한 역할 90초 × 네 역할 = 게임 약 6분 + 퀴즈 시간**입니다. 시작 화면의 ‘체험 시간·숲 친구 바꾸기’에서 60·90·120초와 처음 숲 친구 8·12·16마리를 고를 수 있습니다. 기본은 12마리로 시작하며, 이후 역할에 맞춰 먹이 동물을 추가합니다.

| 90초 미션 | 목표 |
|---|---|
| 메뚜기 | 벼 5개 이상 |
| 개구리 | 메뚜기 3마리 이상 |
| 뱀 | 개구리 2마리 이상 |
| 매 | 뱀 2마리 이상 |

시간을 바꾸면 목표 수도 비례해서 바뀝니다. 잡혀도 이번 역할에서 먹은 수는 유지되고, 다음 역할에서 새로 시작합니다. 목표를 채우지 못해도 네 역할을 모두 체험할 수 있습니다.

## 조작

- 이동: 왼쪽 조작판, 방향키, WASD, 또는 맵의 빈 곳 누르기.
- 특수 동작: 오른쪽 행동 버튼 또는 스페이스.
- 메뚜기: 바라보는 방향으로 나무·바위를 훌쩍 뛰어넘기.
- 개구리: 앞쪽으로 혀 뻗기. 뱀: 잠시 숨기. 매: 빠르게 내려오기.
- 메뚜기·개구리·뱀은 나무 가까이나 풀숲에서 멈추면 처음 3초 동안 잡히지 않습니다. 이후에는 숨어 있어도 잡힙니다. 구역 밖에 1초 이상 있어야 다시 보호받습니다.
- 잡히면 2.5초 뒤 재출발하고, 재출발 직후에는 3초 동안 보호받습니다.
- 다른 탭으로 이동하거나 창이 비활성화되면 자동으로 멈춥니다. 돌아와서 ‘계속 탐험하기’를 누릅니다.

## 수업 활용과 기록

로그인·이름 입력·서버 전송이 없습니다. 기록은 열린 페이지 안에서만 유지되며, 새로고침하거나 처음으로 돌아가면 초기화됩니다. 교사가 기록을 모으려면 학생이 마지막 기록 화면을 보여주거나 직접 화면을 캡처해 제출하도록 안내할 수 있습니다.

발문 예: ‘개구리는 무엇을 먹고, 누구에게 먹혔나요?’, ‘먹기도 하고 먹히기도 하는 생물은 누구였나요?’, ‘화살표는 어느 쪽으로 이어야 할까요?’

학생이 다른 동물 역할을 맡는 놀이이며 생물이 다른 종류로 변하는 과정은 아닙니다. 교과서의 대표 먹이사슬을 단순화했고, 실제 자연에는 다양한 먹이그물이 있습니다.

## 코드 수정과 검사

실행할 때 설치가 필요하지 않습니다. 개발용 원본은 `source/`에 있습니다. 코드를 고친 뒤 Python 3으로 `python3 build.py`를 실행하면 완성된 `index.html`이 다시 만들어집니다. 개발 검사는 Node로 `node --test tests/*.test.mjs`를 실행합니다. 별도 npm 패키지를 설치하지 않습니다.

- `source/engine.js`: 이동, 먹이, 숨기, 점프와 컴퓨터 생물.
- `source/solo-state.js`: 네 역할 진행, 퀴즈와 개인 기록.
- `source/audio.js`: 내장 BGM 합성, 효과음과 내 캐릭터의 소리 판정.
- `source/solo.js`, `source/style.css`, `source/shell.html`: 개인용 조작과 화면.
- `source/render.js`, `source/motion-view.js`: 숲과 캐릭터 표시.
- `source/assets-inline.json`: 파일 안에 들어가는 그림.
- `ASSET_PROMPT.txt`: 기존 도트 그림의 제작 안내.
