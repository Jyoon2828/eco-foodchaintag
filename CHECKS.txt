먹이사슬 술래잡기 개인 체험용 1.4.0
검사일: 2026-10-22

자동 검사 52개 통과
- 개인 시작/설정/일시정지/네 역할/네 퀴즈/기록/다시 시작/점프/숨기/오프라인 검사
- 60·90·120Hz 표시 조건을 코드에서 재현해 등속 이동의 정지/이동 반복 현상 방지
- 대각선 근처 작은 각도 변화의 방향 그림 깜빡임 방지
- 과도한 상하 들썩임 제한, 뱀의 수직 튀기 없음
- 화면 보정이 실제 위치·점수·미션 판정을 변경하지 않음
- 보통 설정에서 메뚜기 8/개구리 7/뱀 6마리 배치 및 일부 먹이의 가까운 출발
- 먹이가 되는 컴퓨터 동물의 이동속도가 학생의 추격속도보다 느림
- 역할 변경/재시작 시 숲 친구 수가 중복 누적되지 않음
- 컴퓨터 생물의 급격한 방향 뒤집기 방지 및 맵 경계 유지
- 자동 추격 입력으로 개구리/뱀/매의 먹이 미션을 90초 안에 완료
  (학생 플레이 시간을 실측한 결과는 아님)

추가 먹이그물 검사
- 기존 다섯 생물의 네 연결을 그대로 가져오며 새 관계 여섯 개로 확장
- 화살표 방향, 중복 연결 방지, 자기 자신 선택 취소, 단서 밖 관계 안내
- 새 연결 삭제/되돌리기/초기화가 가져온 먹이사슬을 지우지 않음
- 전체 관계 확인 전 다음 단계 이동 방지, 연결 수정 시 확인 상태 초기화
- 개구리 가리기는 두 직접 연결만 흐리게 하며 다른 생물을 자동 제거하지 않음
- 개구리를 가린 뒤 생쥐와 참새라는 두 대체 먹이를 모두 찾아야 생각 정리로 이동
- 개인 생각 글자 수 제한, 공백만 있는 기록 방지, 새 활동에서 기록 초기화
- 다른 먹이사슬 강조가 연결 자료를 바꾸지 않음
- 모든 화살표가 먹히는 생물에서 출발해 먹는 생물 카드 바깥에서 끝남

추가 그림 퀴즈 검사
- 두 그림 → 세 그림 → 세 그림 → 다섯 그림으로 이어지는 먹이사슬
- 각 퀴즈의 모든 순열을 검사해 먹히는 생물 → 먹는 생물 순서 한 가지만 정답 처리
- 잘못된 ID/중복 카드/불완전한 배열/예전 보기 번호의 통과 방지
- 그림 선택 칸은 정답 순서로 미리 정렬하지 않으며, 필요한 그림이 각각 한 번만 있음
- 되돌리기/지정 그림부터 다시 놓기/전체 초기화 후 재연결 가능
- 틀린 첫 먹이관계 표시, 올바른 그림 연결 전 다음 역할 이동 불가
- 각 생물 그림에 이름·버튼 설명 표시, 성공 후에는 완성된 연결 유지
- 퀴즈 정답 배열을 역할별 기록에 복사해 보관하고 재시작 때 초기화

추가 오디오 검사
- 사용자 동작 전에는 AudioContext를 만들거나 BGM을 예약하지 않음
- BGM/효과음을 각각 끄기, 음량 0에서 소리/음악 예약 중단
- 90초 모의 오디오 시간 동안 음악 예약 타이머가 하나만 유지되고 음성 수가 누적되지 않음
- 동시 합성 음성 최대 48개, 같은 효과음 0.12초 안 중복 방지
- 잠깐 멈춤/창 비활성화/다른 탭 이동에서 예약된 음과 진행 중 음을 해제
- 지원하지 않는 오디오 API, 소리 재개 거부에서 게임 진행을 방해하지 않음
- 내 캐릭터의 행동만 재생하고 미션 성공음은 역할별 1회만 재생
- 다시 시작 시 이벤트/미션 소리 기록 초기화, 일시정지 중 지난 행동 소리가 나지 않음

완성된 index.html 전체 스크립트를 DOM 대역과 실제 네이티브 캔버스로 실행한
통합 스모크 검사 통과: 시작, 이동, 점프, 잠깐 멈춤/재개, 도움말,
네 역할의 그림 먹이사슬 오답/정답/다음 역할, 마지막 기록, 다시 시작.
그림 카드 누르기, 다 놓기 전 확인 비활성화, 중복 선택 방지,
틀린 연결 표시, 하나 되돌리기/전체 초기화/중간 그림부터 다시 연결,
도움말·소리 설정 전후 연결 상태 유지 확인.
소리 설정 열기/닫기, BGM/효과음 개별 조절, 음량, 미리 듣기,
설정 중 탭 이동 후 자동 재개 방지, 창 비활성화 후 명시적 재개도 확인.
먹이사슬 기록 → 먹이그물 진입 → 연결/반대 방향 안내/삭제/되돌리기/초기화 →
개구리 가리기 → 다른 먹이 두 가지 찾기 → 내 생각 → PNG 저장까지 통과.
게임 기록을 보존한 재진입, 시작 화면에서 먹이그물만 진입, 처음으로 이동 취소,
새 활동 초기화와 작은 화면 가로 이동 위치/관계 목록 펼침 유지도 확인.
새 그림은 CSS 속성으로 한 번 설정해 카드 선택 때마다 큰 이미지 문자열을
다시 넣지 않음. 동물 PNG 두 장의 투명 배경(알파 0~255) 확인.
오디오 API가 없는 경우와 오디오 API 대역이 있는 경우 모두 통과.
실제 내장 그림과 한국어 글꼴을 등록한 네이티브 캔버스로 저장 PNG를 만들고,
1600×1420 크기, 모든 생물/화살표/한국어 라벨/개인 설명 표시를 시각 확인.
이 검사에서 외부 요청 0회. 내장 도트 그림을 실제 캔버스로 그리는 것 확인.

모든 원본 JavaScript와 최종 HTML 안 스크립트 구문 검사 통과.
최종 HTML에는 외부 URL, 외부 스크립트/스타일시트, fetch, WebSocket,
Firebase SDK, API 설정이 없음. 실행 시 설치나 빌드가 필요 없음.
학급 공동접속용 파일은 수정하지 않음.

한계: 실제 갤럭시탭/브라우저별 화면 주사율이나 프레임 속도를 측정한 결과는 아님.
실제 갤럭시탭의 터치·화면 배치나 브라우저 자동화는 실행하지 못했으며, 위 통합 검사는 DOM 대역/네이티브
캔버스와 오디오 API 대역을 사용함. 실제 스피커 출력/기기별 음량을 실측하거나
실제 브라우저에서 청취한 결과는 아님. 각 기기의 체감 움직임과 소리는 기기에서 확인해야 함.
